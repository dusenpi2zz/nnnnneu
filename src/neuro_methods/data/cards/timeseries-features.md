# 时间序列特征与预测验证

ID：`timeseries-features` · 领域：timeseries · 实现：reference_only

## 研究问题

把时间结构转为可解释特征，同时保留采样和验证条件。

## 流程、输入输出与检查

执行路径：明确采样率、长度、平稳性和标准化；列出每个特征含义；按独立被试或独立实验划分训练/验证；只在训练折拟合归一化和特征选择。

质量与解释边界：同一被试的窗口不可随意跨训练测试集；长度、噪声和采样率差异可能伪装成组间效应。这里尚未实现 catch22 调用。

当前仅完成方法卡，尚未包装运行流程。下一步必须由具体研究数据和问题确定最小可验收案例。
