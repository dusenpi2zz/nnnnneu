# 网络指标与匹配零模型

ID：`network-nulls` · 领域：networks · 实现：reference_only

## 研究问题

判断网络统计量是否超出明确零假设所能解释的范围。

## 流程、输入输出与检查

执行路径：明确有向/无向、加权/二值及负边处理；写出零模型应保留的性质；验证随机化确实保持约束；记录种子、次数、统计量和比较族。

质量与解释边界：网络重连零模型、时间序列替代数据与空间零模型回答不同问题，不可替换。阈值和密度变化需敏感性检查。

当前仅完成方法卡，尚未包装运行流程。下一步必须由具体研究数据和问题确定最小可验收案例。
