# 参数恢复与实际可辨识性

ID：`identifiability` · 领域：identifiability · 实现：reference_only

## 研究问题

区分拟合良好、参数可恢复与机制可区分。

## 流程、输入输出与检查

执行路径：定义观测与噪声模型；合成数据参数恢复；多初值优化；profile likelihood 时固定目标参数并重新优化其他参数；检查边界、优化失败和采样设计。

质量与解释边界：单点最优拟合不证明参数正确；固定其他参数的扫描不是 profile likelihood。结构与实际可辨识性不能混为一谈；具体阈值需符合统计条件。

当前仅完成方法卡，尚未包装运行流程。下一步必须由具体研究数据和问题确定最小可验收案例。
