# LFPy：从神经元模型到细胞外电信号

ID：`lfpy` · 领域：electrophysiology · 工具本身由上游维护。

## 研究问题

给定神经元形态、膜机制、输入活动和电极位置，预测这些模型会产生什么细胞外电信号。它位于生成模型与观测模型之间，可与动力系统和可辨识性模块衔接。

## 方法与范围

LFPy 使用 NEURON 的多室模型计算跨膜电流，并通过体积导体模型预测细胞外电位。LFPy 2.x 也提供与网络、偶极矩及 EEG/MEG 预测有关的能力。不同层级需要不同的模型与几何信息；本库示例只覆盖单个被动细胞和均匀介质中的线源预测。

## 输入、输出和单位

输入包括形态、膜参数、刺激/突触协议、电极位置与电导率。典型输出为时间、电压、跨膜电流与电极电位。必须注明 μm、ms、mV、nA 和 S/m；mV 转 μV 要乘 1000。

## 适用条件与边界

线源示例假定无限均匀、各向同性且电导率不随频率变化的介质。组织边界、各向异性、有限接触面积和复杂头模型需要另行处理。预测与记录相似不证明形态或机制唯一；改变电极位置、电导率、形态与输入可能产生混淆。

## 运行入口

`neuro-methods show lfpy-passive-demo` 查看本库的最小运行方法。依赖放在独立 Linux 环境；本机核心 Windows 环境没有安装 LFPy/NEURON。2026-09-08 核实的 PyPI 版本为 LFPy 2.3.7、NEURON 9.0.2，后者未提供 Windows wheel；这不等同于 NEURON 不支持任何 Windows 安装方式。
