# CellReg (Ziv lab)

ID：`cellreg` · 领域：calcium · 本库状态：仅资料，未验证运行。

## 研究问题与用途

通过概率模型跨 session 匹配同一细胞。

## 输入与输出

各 session 的细胞空间足迹；跨 session 对应关系。具体文件结构以所固定版本文档为准。

## 方法选择与执行路径

先核实坐标与尺度，再检查配准、匹配概率和阈值敏感性，保留未匹配项。

## 假设、质量检查与失败条件

输入是已提取空间足迹；匹配仍有不确定性，不把未匹配等同于细胞消失。
