# 扩展路线

以真实研究任务驱动，每个模块都通过同一套来源、运行、负例、项目验收过程。

| ID | 工作 | 验收条件 | 状态 |
|---|---|---|---|
| BASE-01 | 方法卡、检索和状态区分 | 图中条目可检索；不明项明确标记 | 已实现 |
| BASE-02 | 运行记录和重放 | 哈希/源码/环境变化会被发现；失败保留记录 | 已实现，见验证记录 |
| CA-01 | ROI 与 Suite2p 输出处理 | 数值正例、负例、合成演示 | 已实现，真实数据待验收 |
| CA-02 | 原始视频完整提取 | 指定公开数据、固定 Suite2p/CaImAn 版本、人工 QC、资源测量 | 未开始 |
| CA-03 | 动态基线与神经毡敏感性 | 明确漂白/背景场景及失败对照 | 未开始 |
| LFP-01 | LFPy 被动细胞正向模型 | 独立后端、单位、有限数值、sigma 缩放及重放 | 已编写，Linux 后端验证待完成 |
| LFP-02 | 真实形态与细胞群观测 | 形态/机制来源、dt/nseg 收敛、几何敏感性和数据对照 | 未开始 |
| FMRI-01 | BIDS→前处理→区域信号 | 一个公开示例、视觉 QC、去噪敏感性及报告 | 方法卡已整理 |
| TS-01 | 特征与验证拆分 | 特征含义、数据泄漏负例、被试层验证 | 方法卡已整理 |
| NET-01 | 匹配零模型 | 明确保留性质、验证随机化与统计比较 | 方法卡已整理 |
| DYN-01 | ODE 与观测模型 | 简化解析例、数值收敛、单位与状态映射 | 方法卡已整理 |
| ID-01 | 参数恢复与 profile | 多初值、重优化、已知不可辨识反例 | 方法卡已整理 |

这些状态指本库中的实现，不代表研究者已掌握或科学任务已完成。近期先以现有研究项目决定 CA-02 和 FMRI-01 谁先推进；不要为凑齐目录同时包装所有后端。
