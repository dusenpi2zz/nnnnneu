# Sources and third-party tools

This repository contains original integration code and short method summaries with links.
It does not vendor Suite2p, CaImAn, MATLAB tools, their full documentation, papers or research datasets.

The MIT license applies only to original material in this repository. Third-party software,
datasets and publications retain their own licenses, usage conditions and citation requirements.
Before adding an executable backend or copying upstream code, inspect the exact version's license
and record the integration decision. A catalog entry does not grant redistribution rights.

Original screenshot entries are represented in the method catalog. The screenshot's publication
context was not supplied; uncertain bibliography and the MOSAIC plugin identity are explicitly
left unresolved rather than guessed. Maintenance statements come from the linked official READMEs.

The source audit date is 2026-09-08. Live documentation can change; execution validation only
covers environments and data reported in docs/VALIDATION.md.
